# Kinder frontend

Первый frontend-прототип для ручного свайпинга. Telegram-бот здесь не используется.

## Сейчас работает

- карточки рекомендаций;
- Like / Dislike;
- клавиши стрелок;
- счётчик матчей;
- смена города;
- новая подборка после смены города;
- состояние окончания рекомендаций.

Сейчас используется mock-режим, поэтому index.html можно открыть напрямую.

## Интеграция

Следующим этапом mock-слой заменяется HTTP API backend: профиль, рекомендации, like, dislike, город и количество матчей.
